Contains
every node = initializes contains to false, iterate through each child,if the child.Value is the target we are looking for then set contains to true & break and return the contains, otherwise call the Contains method again with the child,target arguments if contains was never set to true then return false

DepthFirstPreOrder
every node = make a result list and add the node to the list,iterates through each child if the child is a leaf then add it to the list, otherwise make a new list with the recursive method with the child as an argument & add the Childs to the result list
finally returns the result list

MaxDepth
every node = initalizes maxdepth to 0 iterates through each child in the node,sets depth to 1+recursive method with child argument,if the depth is larger than maxdepth then set maxdepth to depth,finally return maxdepth
